This tool parses FPP source files into an abstract syntax tree (AST),
optionally transforms the AST, and writes out the AST as formatted source code.

The main purpose of this tool is to rewrite FPP constructs such
as include specifiers and template expansions into a standard form.
It also writes formatted output, and it can be used for that purpose.
It is not a true formatter, in that (1) it requires syntactically valid
FPP source as input and (2) it erases comments.
However, it may be useful for some formatting tasks.

To preserve comments on their own lines
that precede annotatable elements, you can run this
script:

[source,bash]
----
#!/bin/sh
sed 's/^\( *\)#/\1@ #/' | fpp-to-fpp $@ | sed 's/^\( *\)@ #/\1#/'
----

It converts comments to annotations, runs `fpp-to-fpp`, and converts
the annotations back to comments.

*Options:*

. `-i` _files_: Import _files_.
The definitions in these files are part of the FPP model, but they do not cause 
any code to be generated.

. `-e`: Expand syntax.
Resolve include specifiers and expand templates.

*Input:*

. A list _fl_tr_ of files to translate: either the single file _stdin_ or a list of 
files specified on the command line.

. A list _fl_i_ of files to import, specified as arguments to the `-i` option.

*Output:* Formatted FPP source code, minus comments, written to standard
output.

*Procedure*:

. Parse each of the files in the concatenation of _fl_tr_ and _fl_i_, generating
a translation unit list _tul_.

. If `-e` is present, then 
https://github.com/nasa/fpp/wiki/Expand-Syntax-and-Enter-Symbols[expand 
syntax and enter symbols], generating a new translation unit list _tul'_.
Otherwise let _tul'_ be _tul_.

. Let _tul_tr'_ be the set of translation units in _tul'_ corresponding
to _fl_tr_.

. Write out the formatted source code for _tul_tr'_.
