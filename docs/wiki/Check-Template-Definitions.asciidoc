This algorithm traverses a source model and checks template
definitions for correctness.

== Input

. A list _tul_ of translation units.

. An
https://github.com/nasa/fpp/wiki/Analysis-Data-Structure[analysis
data structure] _a_
representing the results of analysis so far.

== Output

. None if the check passes; otherwise an error.

== Procedure

Currently this analysis does the following:

. Check that no template definition transitively contains a template definition.

. Check that no template definition transitively contains a template expansion.

. Check that no template definition transitively contains a system definition

Eventually we will implement all of the checking described in the
https://nasa.github.io/fpp/fpp-spec.html#Definitions_Module-Template-Definitions_Semantics[FPP 
specification].
