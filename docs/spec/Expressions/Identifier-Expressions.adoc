=== Identifier Expressions

An *identifier expression* is one of the following:

. An <<Lexical-Elements_Identifiers,identifier>> _I_
that refers to a
<<Definitions_Constant-Definitions,constant definition>>
or
<<Definitions_Enumerated-Constant-Definitions,enumerated constant definition>>,
according to the
<<Scoping-of-Names_Resolution-of-Identifiers,rules for resolving identifiers>>.

. A <<Scoping-of-Names_Qualified-Identifiers,qualified identifier>> `.` _I_,
where _I_ is an identifier, that refers to a
<<Definitions_Constant-Definitions,constant definition>>
according to the
<<Scoping-of-Names_Resolution-of-Qualified-Identifiers,rules for resolving 
qualified identifiers>>.

**Example:**

[source,fpp]
----
constant a = 42
constant b = a # a is an identifier expression
module M {
  constant a = 0
  constant b = .a # .a is an identifier expression
}
----
